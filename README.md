## How I Track Progress

- **`PROGRESS.md`** — master checklist with status per item.
- **GitHub Issues** — one issue per problem, labeled by track (`lld`/`hld`) and status (`todo`/`in-progress`/`done`).
- **Per-problem folders** — notes, design docs, and Java code under `lld/` and `hld/`.

### Status legend

- `[ ]` not started  ·  `[~]` in progress  ·  `[x]` done

### Folder layout

```
lld/
  01-solid-principles/
    NOTES.md        # requirements, approach, patterns used
    src/            # Java implementation
hld/
  01-url-shortener/
    NOTES.md        # requirements, estimation, architecture, trade-offs
    diagrams/       # ASCII / image diagrams
```
